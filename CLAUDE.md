# CLAUDE.md — Переход (Perehod)

## Что это

HTML5-аркада про велосипедиста, который пересекает дорогу по пешеходному переходу, не спешиваясь. Работает как обычная веб-страница и как Telegram Mini App. Сеттинг — Финляндия (по сюжету там разрешено пересекать дорогу по переходу на велосипеде).

Без сборки, без фреймворков: vanilla JS + Canvas 2D. Звук синтезируется через Web Audio API.

## Структура файлов

| Файл | Содержимое |
|---|---|
| `index.html` | Разметка + подключение ресурсов, ~70 строк |
| `style.css` | Все стили |
| `i18n.js` | Словарь переводов `I18N` (7 языков) |
| `game.js` | Весь игровой код |

## Версионирование

Константа `VERSION` в `game.js`, отображается на стартовом экране. **Поднимать при каждом релизе**: багфиксы — патч (0.2.1), новые фичи — минор (0.3). Текущая: 0.2.

## Архитектура game.js (по порядку в файле)

1. **Telegram-инициализация** — объект `TG` (null вне Telegram); `ready()`, `expand()`, `disableVerticalSwipes()`.
2. **Язык** — `LANG`, функция `T(key)` с фолбэком на `ru`. `I18N` живёт в `i18n.js`.
3. **Состояние** — `state`: `menu` → `ready` → `play` → `shop` → … → `over`. `ready` — уровень загружен, трафик едет, игрок ждёт; старт по нажатию газа.
4. **Константы геймплея** — см. таблицу ниже.
5. **Аудио** — `tone()`, `noiseBurst()`, `sfx(name)`; 8 эффектов; тумблер 🔊 в шапке, состояние в localStorage.
6. **Трафик** — `setupLevel()`, `spawnCar()` (с проверкой зазора — машины не должны накладываться), `spawnPolice()`, `moveTraffic(dt)`: индивидуальные скорости (±15% от полосы), случайные торможения (~7%/сек до 45% скорости), car-following (догнал лидера — выровнял скорость и держит дистанцию).
7. **Игрок и скоринг** — `update(dt)`: физика велосипеда, начисления (см. ниже), коллизии, ДПС-штраф.
8. **Рендер** — `draw()`, `drawBike()`, `buildShareCard()` (PNG-карточка 800×450 для шеринга).
9. **UI-оверлеи** — меню, правила, магазин (`showShop(d)` с разбором очков), итог.

## i18n.js

Объект `I18N`, 7 языков: `ru` (default), `fi`, `en`, `sr` (латиница), `cs`, `de`, `kv` (коми, перевод приблизительный).

**Инвариант: набор ключей идентичен во всех языках** — проверять при добавлении строк. Реплики бомбящих водителей (`rage[]`) — локализованы, при добавлении языка не забыть.

## Ключевые константы и баланс

| Что | Где | Значение |
|---|---|---|
| Мин. скорость (нельзя остановиться) | `MINV` | 46 px/s |
| Отображение скорости | `KMH` | px/s × 0.17 → км/ч |
| Полосы | `laneCount()` | `min(level, 8)` — уровень 1 = 1 полоса |
| База за переход | в `update()` | `30 + level*20` |
| Бонус скорости / штраф медлительности | в `update()` | +6/сек при v>95; −4/сек при v<58 (в разборе — одна строка с нетто) |
| Штраф за съезд с зебры | в `update()` | −16/сек; допуск **+8 px наружу** от линии (по краю ехать можно) |
| Проезд впритирку | в `update()` | +5+level/2, один раз на машину, **не сзади** (`behind`-проверка) и не на полицию; триггерит `burnDriver()` |
| ДПС | `setupLevel()`/`spawnPolice()` | с 3-го уровня, шанс 15%/переход, спавн через 1.2–2.7 с после старта и только если игрок ещё не доехал до её полосы; объезд только сзади, проезд перед капотом −30 |
| Апгрейды (скорость/тормоза/управляемость) | `cost(l)` | `40 × 2^lvl`, 5 ступеней |
| Жизнь | `LIFE_COST` | 200 очков, максимум 3 жизни |

Итог уровня не может быть отрицательным (`Math.max(0, …)`). Два счётчика: `scoreTotal` (только растёт, это итог и рекорд) и `coins` (тратится в магазине).

## Правила правок

- Текущий код использует конкатенацию строк вместо template literals — поддерживать единый стиль.
- Все пользовательские строки — только через `I18N`/`T()`, ничего хардкодом.
- Тарифы скоринга держать в `update()` рядом, не размазывать.
- localStorage-ключи: `perehod-best`, `perehod-lang`, `perehod-sound` — все обращения в try/catch.

## Деплой

- **itch.io** — витрина для веба: zip с `index.html`, `style.css`, `i18n.js`, `game.js` в корне, Kind = HTML, Mobile friendly, Portrait.
- **Mini App** — прямой URL (GitHub Pages, т.к. iframe-URL itch нестабилен), зарегистрирован через @BotFather `/newapp`; кнопка меню бота настроена там же. При обновлении игры BotFather трогать не нужно.
- Возможное будущее: `/newgame` + `setGameScore` для лидерборда в чатах (потребует два хендлера и эндпоинт `/score` в существующем FastAPI-боте на Railway).
- Локально открывать через HTTP-сервер (`python3 -m http.server`), не как `file://` — браузер заблокирует загрузку внешних скриптов.

## Известные нюансы

- Шеринг картинкой (`navigator.share` + PNG из `buildShareCard()`) работает в мобильных браузерах; внутри Telegram-вебвью срабатывает фолбэк `TG.openTelegramLink(t.me/share/url)` с текстом.
- Превью ссылки в чатах: добавить `<meta property="og:image">` с абсолютным URL обложки после её загрузки на хостинг.
- AudioContext создаётся лениво и резюмится после первого жеста (требование iOS).
